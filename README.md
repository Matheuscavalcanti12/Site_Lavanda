# StoryRoupas 👗

Loja online de roupas com design moderno em tons de lilás e marrom. Este projeto está vinculado com o outro repositório, Fluxo pedido,
Onde criei as APIS necessárias para o bom funcionamento.


## Funcionalidades

- **Catálogo de Produtos** — admin controla criação  produtos com imagem, descrição e preço
- **Página do Produto** — detalhes completos ao clicar em um item
- **Carrinho de Compras** — adicionar, atualizar quantidade, excluir e finalizar compra, enviando mensagem para whatsApp
- **Login e Cadastro** — telas com ilustrações temáticas
- **Menu de Navegação** — acesso rápido a produtos, cadastro e carrinho

## Tecnologias

- React 18 + TypeScript
- Vite 5
- Tailwind CSS
- shadcn/ui
- React Router

## Como rodar localmente

```bash
Rode primeiro o projeto FluxoPedido com dotnet run em ProjectFiles
Depois rode o site com:

npm install
npm run dev
```

O projeto estará disponível em `http://localhost:5173`.
